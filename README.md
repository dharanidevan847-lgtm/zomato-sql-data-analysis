# zomato-sql-data-analysis

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant data using MySQL. The main objective is to explore restaurant information, clean the dataset, and extract meaningful business insights using SQL queries.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench

## 📊 Project Tasks
- Data exploration and understanding
- Data cleaning and handling missing or inconsistent values
- Identifying and removing unnecessary columns
- Analyzing restaurant ratings and votes
- Analyzing restaurants by country and city
- Analyzing online delivery availability
- Using aggregate functions, GROUP BY and JOINs
- Applying subqueries and window functions

## 🔍 Key Insights
- Analyzed restaurant distribution across different countries and cities.
- Identified average, minimum and maximum restaurant ratings.
- Analyzed online delivery availability across countries.
- Explored restaurant votes and customer engagement.
- Identified top restaurant cities in India.

- Improved practical SQL skills.
- Learned data cleaning and data transformation.
- Practiced business-oriented data analysis.
- Developed experience extracting insights from real-world datasets.
